# Scanning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Find and measure only supported developer artifacts within approved roots.

**Architecture:** Declarative rules feed a cancelable scanner; policy and metadata ports make boundary cases deterministic.

**Tech Stack:** Foundation, CryptoKit, Swift Concurrency, XCTest.

**Spec:** [Approved specification](../specs/2026-09-21-macdevclean-design.md); [contracts](../specs/2026-09-21-interface-contracts.md).

## Global Constraints

- Product: MacDevClean; desktop application from the first runnable milestone.
- Swift 6 language mode; deployment target macOS 14; Xcode 16 or newer, with the exact tested Xcode build recorded.
- UI: English and Brazilian Portuguese; source, commits, technical documentation: English.
- SwiftUI, Observation, structured Swift Concurrency, Foundation, SwiftData and XCTest.
- No production runtime dependencies outside Apple frameworks; any build tooling dependency requires an ADR.
- No sandbox, privileged helper, administrator prompt, telemetry, server, scheduled deletion or background agent.
- Filesystem cleanup is Trash-only; no permanent filesystem deletion or empty-Trash command.
- Docker writes require a confirmed immutable selection, local endpoint verification and typed allowlisted commands.
- Tests operate on owned synthetic fixtures and fake destructive adapters; never on user caches, real Trash or existing Docker resources.
- Follow the approved spec plus the documented technical clarifications in docs/superpowers/specs/2026-09-21-implementation-clarifications.md.
- Do not publish, create remote repositories or upload artifacts without explicit authorization; local branches, commits and merges are authorized.

## Review Focus

- Excluded descendants must block ancestor cleanup: Task 1.
- Folders merely named build must not be guessed disposable: Task 2.
- APFS/hard links and unknown size must not produce false exact totals: Task 3.
- Permission failure in one subtree must preserve other results: Task 3.
- Cancellation must stop enumeration rather than only hide its UI: Task 3.

### Task 1: Policy and filesystem boundary

**Files:** Packages/MacDevCleanCore/Sources/Domain/FileSystemClient.swift, Sources/Scanning/{LocalFileSystem,PathPolicy,ReadOnlyGitClient,InMemoryCandidateStore}.swift, Sources/TestSupport/Fakes.swift, Tests/ScanningTests/PathPolicyTests.swift (all Sources/Tests package-relative); docs/security/filesystem-policy.md.

**Interfaces:** implement FileSystemClient, PathPolicyChecking, GitStatusChecking and CandidateStore from contracts. PathPolicy(files:) consumes lstat-style metadata. InMemoryCandidateStore() owns only live scan snapshots.

- [ ] Add tests using FixtureTree and a MemoryContext configured only for that fixture. Test component matching directly:
```swift
func testSiblingPrefixIsNotAnExcludedDescendant() async throws {
    let tree = try FixtureTree()
    defer { tree.close() }
    let a = try tree.directory("work/app")
    let sibling = try tree.directory("work/application")
    let policy = PathPolicy(files: LocalFileSystem())
    let matches = try await policy.matches(sibling, exclusion: a)
    XCTAssertFalse(matches)
}
```
Add cases: exclusion equal to candidate; exclusion ancestor; exclusion nested inside candidate (blocks whole-directory cleanup); symlink ancestor escape; root equality; other volume; protected subtree. Use fake volume identity where physical volume mounting would be needed.
- [ ] Run `swift test --package-path Packages/MacDevCleanCore --filter PathPolicyTests`; observe missing/incorrect PathPolicy behavior.
- [ ] Implement component comparison with canonical ancestry, case-sensitivity metadata and lstat checks, never `path.hasPrefix(root.path)`. Core decision:
```swift
// Internal helper after URL normalization and volume/case checks:
func componentDescendant(_ candidate: [String], of root: [String]) -> Bool {
    candidate.count > root.count && Array(candidate.prefix(root.count)) == root
}
```
For exclusions test both descendant directions including equality. Deny mounts/symlink ancestors, protected roots/subtrees, cloud placeholder targets, and target/project-root equality. LocalFileSystem bridges bounded utility-queue I/O; check cancellation before/after work. ReadPrefix limit is 256 KiB and throws unsupported for unreadable or larger evidence files instead of evaluating them.
- [ ] Implement read-only Git adapter using fixed /usr/bin/git, separate literal arguments, GIT_OPTIONAL_LOCKS=0 and GIT_LITERAL_PATHSPECS=1. Use `-C <repo> ls-files -z -- <relative path>` and `check-ignore -z -- <relative path>`; stdout split by NUL, bounded output, no shell. Fail closed on timeout or repository mismatch.

### Task 3: Cancelable scanner and honest measurements

**Files:** Packages/MacDevCleanCore/Sources/Scanning/{DeveloperScanner,SizeAccumulator}.swift, Sources/TestSupport/ScanCollector.swift, Tests/ScanningTests/{DeveloperScannerTests,SizeAccumulatorTests}.swift (package-relative); docs/verification/02-scanning.md.

**Interfaces:** DeveloperScanner(files:catalog:git:context:store:) implements ScanService; SizeAccumulator.add(logical:allocated:identity:) throws on arithmetic overflow and deduplicates hard links by device/inode. ScanCollector.collect returns the terminal snapshot.

- [ ] Write tests:
```swift
func testHardLinkBytesAreCountedOnce() throws {
    var sum = SizeAccumulator()
    let identity = FileIdentity(device: 1, inode: 2, modifiedNanoseconds: 0)
    try sum.add(logical: 100, allocated: 4096, identity: identity)
    try sum.add(logical: 100, allocated: 4096, identity: identity)
    XCTAssertEqual(sum.logicalBytes, 100)
    XCTAssertEqual(sum.allocatedBytes, 4096)
}
```
Also test optional unknown size, overflow, roots overlapping, parent/child candidate overlap, newline/emoji filename, permission-denied subtree preserving good results, cancellation of a 100,000-entry fake stream and stale snapshot invalidation. Never sum Docker sizes in this accumulator.
- [ ] Run `swift test --package-path Packages/MacDevCleanCore --filter ScanningTests`; record red for aggregation/orchestration.
- [ ] Implement traversal with deterministic stack, pruning exclusions before descent, identity-based visited set, no mount/symlink/bundle/.git/placeholder descent. Select only maximal non-overlapping cleanup candidates; if an excluded descendant blocks a maximal candidate, skip the ancestor rather than silently trashing the excluded child.
```swift
let (next, overflow) = logicalBytes.addingReportingOverflow(logical)
guard !overflow else { throw MeasurementError.overflow }
logicalBytes = next
```
Define MeasurementError.overflow in SizeAccumulator.swift. Publish progress at most every 100 ms or 256 entries, not once per file; bounding stream buffer must never drop a completed event. Store snapshot before yielding completed. onTermination cancels the producer task; check cancellation each batch and finish with CancellationError without converting cancellation to “no files found.”
- [ ] Add cancellation test consuming one progress event then canceling the consumer. Assert no further filesystem reads after worker shutdown and no completed snapshot; use bounded XCTest expectation rather than arbitrary sleep.

Supported fixture roots produce correct candidates; no traversal follows symlinks/mounts; unknown measurements remain unknown; cancellation stops background work; rule evidence and policy snapshot are registered for the cleanup validator.
