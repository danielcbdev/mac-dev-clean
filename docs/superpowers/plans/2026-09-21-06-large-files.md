# Large Files Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Analyze user-selected folders for large files and route explicit selections through shared safety review.

**Architecture:** Reuse filesystem enumeration and policy; a separate scanner produces registered manual candidates and UI-only metadata.

**Tech Stack:** Foundation, Swift Concurrency, SwiftUI Table, AppKit folder picker, XCTest.

**Spec:** [Approved specification](../specs/2026-09-21-macdevclean-design.md); [contracts](../specs/2026-09-21-interface-contracts.md).

## Global Constraints

- Product: MacDevClean; desktop application from the first runnable milestone.
- Swift 6 language mode; deployment target macOS 14; Xcode 16 or newer, with the exact tested Xcode build recorded.
- UI: English and Brazilian Portuguese; source, commits, technical documentation: English.
- SwiftUI, Observation, structured Swift Concurrency, Foundation, SwiftData and XCTest.
- No production runtime dependencies outside Apple frameworks; any build tooling dependency requires an ADR.
- No sandbox, privileged helper, administrator prompt, telemetry, server, scheduled deletion or background agent.
- Filesystem cleanup is Trash-only; no permanent filesystem deletion or empty-Trash command.
- Docker writes require a confirmed immutable selection, local endpoint verification and typed allowlisted commands.
- Tests operate on owned synthetic fixtures and fake destructive adapters; never on user caches, real Trash or existing Docker resources.
- Follow the approved spec plus the documented technical clarifications in docs/superpowers/specs/2026-09-21-implementation-clarifications.md.
- Do not publish, create remote repositories or upload artifacts without explicit authorization; local branches, commits and merges are authorized.

## Review Focus

- A sibling folder outside selection must remain unvisited: Task 1.
- A file exactly at the threshold must be included: Task 1.
- Cloud placeholders must not download during size discovery: Task 1.
- Sorting or threshold changes must not silently select files: Task 2.
- Revoked root consent must block a previously reviewed file: Task 1.

### Task 1: Explicit-root scanner

**Files:** Packages/MacDevCleanCore/Sources/Domain/LargeFileTypes.swift, Sources/Scanning/LargeFileScanner.swift, Sources/Cleanup/CleanupPlanValidator.swift, Tests/ScanningTests/LargeFileScannerTests.swift (package-relative).

**Interfaces:** LargeFileRequest, LargeFileRow, LargeFileEvent, LargeFileScanning from contracts. LargeFileScanner(files:context:store:) registers candidates in CandidateStore using active largeFileRoots. The cleanup engine's rule catalog recognizes reserved manual.largeFile only with snapshot provenance.

- [ ] Add fixture test:
```swift
func testThresholdIncludesBoundaryWithoutLeavingSelectedRoot() async throws {
    let tree = try FixtureTree()
    defer { tree.close() }
    let selected = try tree.directory("chosen")
    _ = try tree.file("chosen/exact.bin", bytes: 100)
    _ = try tree.file("chosen/small.bin", bytes: 99)
    _ = try tree.file("outside/large.bin", bytes: 200)
    let context = MemoryContext(value: SafetyContext(
        home: tree.root, projectRoots: [], largeFileRoots: [selected],
        globalRuleRoots: [:], exclusions: [], revision: 1))
    let scanner = LargeFileScanner(files: LocalFileSystem(), context: context,
                                   store: InMemoryCandidateStore())
    var rows: [LargeFileRow] = []
    for try await event in scanner.scan(LargeFileRequest(
        roots: [ScanRoot(url: selected)], minimumBytes: 100)) {
        if case .completed(let result, _) = event { rows = result }
    }
    XCTAssertEqual(rows.map { $0.url.lastPathComponent }, ["exact.bin"])
}
```
Use byte-small test thresholds; UI offers only documented presets. Add symlink informational-only, mount boundary, cloud placeholder, package skipping, exclusions, overlapping roots, unselected sibling and cancellation cases.
