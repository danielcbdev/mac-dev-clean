# Code of conduct

## Our standard

Everyone participating in this project is expected to behave respectfully and
professionally. That means:

- Assume good faith and give constructive, specific feedback.
- Critique the code, the design or the evidence — never the person.
- Accept that maintainers may decline a contribution, and say why.
- Respect the project's scope and safety constraints. This tool deletes
  people's data; arguments for loosening a safety boundary need evidence, not
  insistence.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language, deliberate intimidation, publishing someone's private information, and
sustained disruption of discussions or reviews.

## Scope

This applies in all project spaces — issues, pull requests, discussions, commit
messages and code review — and when representing the project elsewhere.

## Reporting

Report concerns to the repository maintainers through the repository's own
channels: open an issue, or use GitHub's private reporting features on this
repository where the maintainer has enabled them.

No other contact is published here. Do not assume a moderation team or an email
address exists.

## Enforcement

Maintainers may edit, hide or reject comments, commits, issues and pull requests
that violate this policy, and may block repeat offenders from the repository.
Enforcement decisions are made by the repository maintainers.
